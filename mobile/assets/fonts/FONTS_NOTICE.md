# Fonts

**Manrope** (weights 400–800, TrueType) — the same family the CropAI web app uses on its
login and admin screens (`next/font/google` → `Manrope`).

- Designer: Mikhail Sharanda
- License: SIL Open Font License 1.1 (https://openfontlicense.org)
- Source: Google Fonts, https://fonts.google.com/specimen/Manrope

Devanagari (Hindi) text is not covered by these files; Android renders it with the system
Noto Sans Devanagari font automatically.
